# Tablet / phone upload (no terminal needed)

1. Download **bajeti-yanga-organised.zip** from the chat.
2. Open the zip (Files app / Google Drive / iCloud usually can open it).
3. On your tablet browser go to:
   https://github.com/Rodart265/bajeti-yanga-organised
4. Tap **Add file** → **Upload files**
5. Upload these from the unzipped folder:
   - `index.html` (replace the existing one)
   - `css/styles.css` (upload into path `css/styles.css` — GitHub creates the folder)
   - `js/app.js`
6. Commit the changes.

Done — the organised project will be fully on GitHub.

Alternatively use the **GitHub mobile app** → open the repo → **+** → **Upload files**.
